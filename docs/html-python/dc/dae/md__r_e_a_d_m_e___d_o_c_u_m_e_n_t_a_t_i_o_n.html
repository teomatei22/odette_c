🚀 Quick Start

Generate Documentation

  1. Automatic Generation (Recommended):
    python generate_docs.py
  2. Manual Generation:
    doxygen Doxyfile
  3. Clean and Regenerate:
    python generate_docs.py --clean

View Documentation

Open the generated HTML documentation:

# Navigate to the HTML output
cd docs/doxygen_output/html
open index.html # macOS
# or
xdg-open index.html # Linux
# or open in your browser on Windows

⚙️ Configuration

Doxyfile Settings

The main Doxygen configuration is in Doxyfile. Key settings:

PROJECT_NAME = "ODETTE Python Interface"
PROJECT_NUMBER = "1.0.0"
PROJECT_BRIEF = "Orbit DETermination TEchnology - Python interface"
OUTPUT_DIRECTORY = ./docs/doxygen_output
INPUT = . docs/
FILE_PATTERNS = *.py *.md *.rst *.txt
USE_MDFILE_AS_MAINPAGE = docs/mainpage.md
GENERATE_HTML = YES
GENERATE_LATEX = NO
HAVE_DOT = YES
CLASS_DIAGRAMS = YES

Customization Options

  1. Project Information: Edit PROJECT_NAME, PROJECT_NUMBER, PROJECT_BRIEF
  2. Input Sources: Modify INPUT and FILE_PATTERNS
  3. Output Formats: Enable/disable GENERATE_HTML, GENERATE_LATEX, etc.
  4. Diagrams: Configure HAVE_DOT, CLASS_DIAGRAMS, CALL_GRAPH

Documentation Best Practices

  1. Python Docstrings:
    def example_function(param1, param2):
    """
    Brief description of the function.
    Detailed description with usage examples.
    @param param1 Description of first parameter
    @param param2 Description of second parameter
    @return Description of return value
    @throws ValueError When invalid input provided
    @code{.py}
    result = example_function("value1", 42)
    print(f"Result: {result}")
    @endcode
    """
    pass
  2. Markdown Documentation:
    # Section Title {#section-id}
    Brief introduction.
    ## Subsection
    Detailed content with:
    - Bullet points
    - Code examples
    - Cross-references: @ref other_section
    @note Important notes for users
    @warning Critical warnings
    @example Example code blocks
  3. Cross-References:
    See @ref getting_started for installation instructions.
    Refer to @ref api_reference "API Documentation" for details.
    Check the @ref examples for practical usage.

🔧 Troubleshooting

Common Issues

  1. Doxygen Not Found
    # Check installation
    doxygen --version
    # Add to PATH if needed (Windows)
    set PATH=%PATH%;C:\Program Files\doxygen\bin
  2. Images Not Displaying
    • Verify image files exist in docs/images/
    • Check image paths in markdown files
    • Ensure images are in supported formats (PNG, JPG, SVG)
  3. Broken Cross-References
    • Verify target section IDs exist
    • Check spelling in @ref commands
    • Ensure referenced files are included in INPUT
  4. Empty Documentation
    • Check file patterns in Doxyfile
    • Verify input directories exist
    • Review Doxygen warnings and errors

Debug Mode

Run with verbose output:

# Enable Doxygen warnings
doxygen -w html configfile
# Edit configfile to set QUIET = NO, WARNINGS = YES
# Generate with warnings
doxygen configfile

Validation

Check documentation quality:

# Validate links (requires linkchecker)
pip install linkchecker
linkchecker docs/doxygen_output/html/index.html
# Check for broken references
grep -r "@ref" docs/ | grep -v "\.html"

Odette Master Website

Orbit DETermination TEchnology, a.k.a. Odette, is a project that aims to simulate low-Earth orbit satellite trajectories. The project consists of a C++ computational core, upon which a high-level Python interface is built in order to facilitate user experience. We also provide a Java graphical interface, appropriate for users with no programming experience that wish to use our software.

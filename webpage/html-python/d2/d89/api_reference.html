Core Classes

OrbitVisualizer

The OrbitVisualizer class provides comprehensive 3D visualization capabilities for satellite orbits.

Constructor

OrbitVisualizer()

Initializes the visualizer with default Earth parameters.

Key Methods

visualize_tle()

visualize_tle(tle_line1, tle_line2, time_span_hours=6, step_minutes=0.5,
show_plot=True, save_path=None)

Visualizes satellite orbit using TLE data with SGP4/SDP4 propagation.

Parameters:

  • tle_line1 (str): First line of TLE data
  • tle_line2 (str): Second line of TLE data
  • time_span_hours (float): Time span to propagate in hours (default: 6)
  • step_minutes (float): Time step between points in minutes (default: 0.5)
  • show_plot (bool): Whether to display the plot (default: True)
  • save_path (str, optional): File path to save the plot

Returns:

  • tuple: (figure, axes, positions) or (None, None, None) on error

Example:

visualizer = OrbitVisualizer()
fig, ax, pos = visualizer.visualize_tle(line1, line2, time_span_hours=12)

visualize_rk45()

visualize_rk45(tdm_wildcard, delta, delta_error, time_span_hours=6,
step_minutes=0.5, perturbations=None, show_plot=True, save_path=None)

Visualizes orbit using RK45 numerical integration with perturbation models.

Parameters:

  • tdm_wildcard (str): Wildcard pattern for TDM observation files
  • delta (float): Delta parameter for TDM parsing tolerance
  • delta_error (float): Delta error parameter for TDM parsing
  • time_span_hours (float): Time span to propagate in hours
  • step_minutes (float): Time step between output points in minutes
  • perturbations (dict): Perturbation flags:
    • ‘'j2’ (bool): J2 Earth oblateness perturbation
    • 'third_body' (bool): Third-body (Moon/Sun) effects
    • 'solar_radiation' (bool): Solar radiation pressure
    • 'atmospheric_drag' (bool): Atmospheric drag modeling
  • show_plot (bool): Whether to display the plot
  • save_path` (str, optional): File path to save the plot

Returns:

  • tuple: (figure, axes, positions) or (None, None, None) on error

Example:

perturbations = {'j2': True, 'third_body': True, 'solar_radiation': False}
fig, ax, pos = visualizer.visualize_rk45("data/*.tdm", 100, 30,
perturbations=perturbations)

OrbitPropagator

The OrbitPropagator class extends OrbitVisualizer to provide advanced orbit propagation with detailed analysis capabilities.

Constructor

OrbitPropagator()

Inherits from OrbitVisualizer and sets up additional propagation-specific parameters.

Key Methods

propagate_tle()

propagate_tle(tle_line1, tle_line2, time_span_hours=6, step_minutes=0.5, return_vectors=True)

Performs TLE-based orbit propagation with detailed orbital elements analysis.

Parameters:

  • tle_line1 (str): First line of TLE data
  • tle_line2 (str): Second line of TLE data
  • time_span_hours (float): Time span for propagation in hours
  • step_minutes (float): Time step between output points in minutes
  • return_vectors (bool): Whether to include position and velocity vectors in output

Returns:

  • dict: Propagation results containing:
    • ‘'epochs’ (list): List of Julian dates
    • 'orbital_elements' (list): List of orbital element dictionaries with keys:
      'a' (float): Semi-major axis in km
      'e' (float): Eccentricity
      'i' (float): Inclination in radians
      'raan' (float): Right Ascension of Ascending Node in radians
      'argp' (float): Argument of Perigee in radians
      'nu' (float): True Anomaly in radians
      'M' (float): Mean Anomaly in radians
    • 'positions' (list): Position vectors (if return_vectors=True)
    • 'velocities'` (list): Velocity vectors (if return_vectors=True)

Example:

propagator = OrbitPropagator()
results = propagator.propagate_tle(line1, line2, time_span_hours=24)
if results:
print(f"Propagated {len(results['epochs'])} epochs")
initial_sma = results['orbital_elements'][0]['a']
final_sma = results['orbital_elements'][-1]['a']
print(f"SMA change: {final_sma - initial_sma:.3f} km")

propagate_rk45(tdm_wildcard, delta, delta_error, time_span_hours=6, step_minutes=0.5,
perturbations=None, return_vectors=True)

Performs high-precision numerical orbit propagation using RK45 integration.

Parameters:

  • tdm_wildcard (str): Wildcard pattern for TDM observation files
  • delta (float): Delta parameter for TDM parsing tolerance
  • delta_error (float): Delta error parameter for TDM parsing
  • time_span_hours (float): Time span for propagation in hours
  • step_minutes (float): Time step between output points in minutes
  • perturbations (dict, optional): Perturbation configuration (default: all False)
  • return_vectors (bool): Whether to include position and velocity vectors

Returns:

  • dict: Same structure as propagate_tle() but with RK45-computed values

compare_orbital_elements()

compare_orbital_elements(tle_line1=None, tle_line2=None, tdm_wildcard=None,
delta=100, delta_error=30, time_span_hours=24, step_minutes=5,
time_offset_minutes=28.5, r_init=None, v_init=None, jd_init=None,
perturbations_list=None, show_plot=True, save_path=None)

Performs comprehensive comparison of orbital element evolution between different propagation methods.

Parameters:

  • tle_line1 (str, optional): First line of TLE
  • tle_line2 (str, optional): Second line of TLE
  • tdm_wildcard (str, optional): Wildcard pattern for TDM files
  • delta (float): Delta parameter for TDM parsing
  • delta_error (float): Delta error parameter for TDM parsing
  • time_span_hours (float): Time span for comparison in hours
  • step_minutes (float): Time step between analysis points in minutes
  • time_offset_minutes (float): Time offset between TLE and observations
  • r_init (array, optional): Initial position vector [x, y, z] in km
  • v_init (array, optional): Initial velocity vector [vx, vy, vz] in km/s
  • jd_init (float, optional): Initial Julian date
  • perturbations_list (list, optional): List of perturbation configuration dictionaries
  • show_plot (bool): Whether to generate comparison plots
  • save_path (str, optional): Base path for saving plots

Returns:

  • dict: Statistical comparison results with keys like 'TLE_vs_RK45' containing:
    • ‘'mean_position_diff’ (float): Mean position difference in km
    • 'max_position_diff' (float): Maximum position difference in km
    • 'std_position_diff' (float): Standard deviation of position differences
    • 'mean_semi_major_diff' (float): Mean semi-major axis difference
    • 'mean_ecc_diff' (float): Mean eccentricity difference
    • 'mean_inc_diff'` (float): Mean inclination difference

set_perturbation_parameters()

set_perturbation_parameters(params)

Configures physical parameters used in perturbation force modeling.

Parameters:

  • params (dict): Dictionary of perturbation parameters:
    • ‘'CR’ (float): Coefficient of reflectivity for SRP (typically 1.0-2.0)
    • 'Am' (float): Area-to-mass ratio in m²/kg
    • 'CD' (float): Drag coefficient (typically 2.0-2.5)
    • 'Sc' (float): Solar constant in W/m²
    • 'nu' (float): Solar flux variation factor
    • 'H0' (float): Atmospheric scale height in km
    • 'rho0'` (float): Reference atmospheric density in kg/m³

Returns:

  • bool: True if parameters were set successfully, False otherwise

Example:

params = {
'CR': 1.8, # Radiation pressure coefficient
'Am': 0.01, # Area-to-mass ratio (m²/kg)
'CD': 2.2 # Drag coefficient
}
success = propagator.set_perturbation_parameters(params)

get_perturbation_parameters()

get_perturbation_parameters()

Retrieves current values of all perturbation model parameters.

Returns:

  • dict: Dictionary of current perturbation parameters including SRP, drag, and gravitational constants

JavaGUIBridge

The JavaGUIBridge class provides a standardized interface for Java applications to interact with the Orbit Toolkit Python code.

Constructor

JavaGUIBridge()

Creates instances of OrbitVisualizer and OrbitPropagator for Java communication.

Key Methods

set_status_callback()

set_status_callback(callback_func)

Sets a callback function for progress updates during long-running operations.

Parameters:

  • callback_func (callable): Function that accepts (progress_percent, status_message) where progress_percent is 0-100 and status_message is a string

execute_command()

execute_command(command_json)

Main entry point for Java applications to execute Orbit Toolkit commands.

Parameters:

  • command_json (str): JSON string containing the command and parameters

Returns:

  • str: JSON response with 'status' field ('success' or 'error') and results or error information

Supported Commands:

  • ‘'visualize_tle’: TLE orbit visualization
  • 'visualize_rk45': RK45 orbit visualization
  • 'compare_orbits': Compare TLE vs RK45 propagation
  • 'propagate_tle': TLE orbit propagation with analysis
  • 'propagate_rk45': RK45 orbit propagation with analysis
  • 'compare_orbital_elements': Comprehensive orbital elements comparison
  • 'set_perturbation_params': Set perturbation model parameters
  • 'get_perturbation_params'`: Get current perturbation parameters

Example:

bridge = JavaGUIBridge()
command = {
'command': 'visualize_tle',
'tle_line1': line1,
'tle_line2': line2,
'time_span_hours': 6,
'save_path': 'output.png'
}
result = bridge.execute_command(json.dumps(command))
response = json.loads(result)

Constants and Defaults

Physical Constants

  • EARTH_RADIUS: 6378.0 km
  • MU_EARTH: 398600.4418 km³/s² (Earth's gravitational parameter)
  • J2: 1.08262668e-3 (Earth's J2 coefficient)

Default Parameters

  • time_span_hours: 6.0
  • step_minutes: 0.5
  • delta: 100.0 (TDM parsing)
  • delta_error: 30.0 (TDM parsing)

Perturbation Defaults

  • CR: 1.3 (Solar radiation pressure coefficient)
  • Am: 0.01 m²/kg (Area-to-mass ratio)
  • CD: 2.2 (Drag coefficient)

Error Handling

Exception Types

  • ImportError: Missing dependencies or failed C++ module import
  • ValueError: Invalid input parameters or data formats
  • FileNotFoundError: Missing TDM files or invalid paths
  • RuntimeError: Propagation failures or computation errors

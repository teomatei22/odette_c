ODETTE Python Interface Documentation

Overview

ODETTE (Orbit DETermination TEchnology) Python Interface provides a comprehensive toolkit for satellite tracking, orbit determination, and trajectory visualization. This high-performance library combines Python's ease of use with C++ computational efficiency through sophisticated bindings.

🚀 Key Features

Core Capabilities

  • TLE (Two-Line Element) Processing: Parse and propagate satellite orbits using SGP4/SDP4 models
  • High-Precision RK45 Integration: Numerical orbit propagation with configurable perturbation models
  • Advanced Visualization: Interactive 3D orbit displays with Earth representation
  • Multi-Satellite Support: Simultaneous tracking and comparison of multiple satellites
  • Comprehensive Analysis: Orbital elements evolution and statistical comparisons

Perturbation Models

  • J2 Earth Oblateness: Primary gravitational perturbation
  • Third-Body Effects: Moon and Sun gravitational influences
  • Solar Radiation Pressure: Photon momentum transfer effects
  • Atmospheric Drag: Exponential atmosphere model for LEO satellites

Data Formats

  • TLE: Standard Two-Line Element format for satellite ephemeris
  • TDM: Tracking Data Message format for observation data
  • JSON: Configuration and result serialization
  • PNG/SVG: High-quality plot exports

📚 Architecture

The ODETTE Python Interface consists of three main components:

1. Core Classes

  • OrbitVisualizer: 3D visualization and plotting capabilities
  • OrbitPropagator: Orbit propagation and analysis engine
  • JavaGUIBridge: Java-Python interface for GUI applications

2. C++ Bindings

  • satellite_core: High-performance C++ computational backend
  • PyBind11 Integration: Seamless Python-C++ data exchange
  • Eigen3 Support: Efficient linear algebra operations

3. Supporting Modules

  • Logging System: Comprehensive operation tracking
  • Configuration Management: Flexible parameter handling
  • Error Handling: Robust exception management

🎯 Quick Start

Basic Orbit Visualization

from orbit_toolkit import OrbitVisualizer
# Create visualizer
visualizer = OrbitVisualizer()
# TLE data for ISS
tle_line1 = "1 25544U 98067A 08264.51782528 -.00002182 00000-0 -11606-4 0 2927"
tle_line2 = "2 25544 51.6416 247.4627 0006703 130.5360 325.0288 15.72125391563537"
# Visualize orbit
fig, ax, positions = visualizer.visualize_tle(
tle_line1, tle_line2,
time_span_hours=6,
show_plot=True
)

Advanced Propagation

from orbit_toolkit import OrbitPropagator
# Create propagator
propagator = OrbitPropagator()
# Configure perturbations
perturbations = {
'j2': True,
'third_body': True,
'solar_radiation': True,
'atmospheric_drag': False
}
# RK45 propagation
results = propagator.propagate_rk45(
tdm_wildcard="data/*.tdm",
delta=100, delta_error=30,
time_span_hours=24,
perturbations=perturbations
)

Java Integration

from orbit_toolkit import JavaGUIBridge
import json
# Create bridge
bridge = JavaGUIBridge()
# Execute command from Java
command = {
'command': 'compare_orbits',
'tle_line1': line1,
'tle_line2': line2,
'tdm_wildcard': 'data/*.tdm',
'time_span_hours': 12
}
result = bridge.execute_command(json.dumps(command))

🛠 Technical Specifications

System Requirements

  • Python: 3.8+ with NumPy, Matplotlib
  • C++ Compiler: C++17 compatible
  • Dependencies: Eigen3, PyBind11, CMake
  • Operating Systems: Windows, Linux, macOS

Performance Characteristics

  • TLE Propagation: ~10,000 epochs/second
  • RK45 Integration: Variable performance based on perturbations
  • Memory Usage: Scales linearly with time span
  • Visualization: Real-time for typical datasets

Accuracy

  • TLE Propagation: Consistent with SGP4/SDP4 standards
  • RK45 Integration: Adaptive step size for optimal precision
  • Frame Transformations: IERS-compliant Earth orientation
  • Perturbation Models: Literature-validated implementations

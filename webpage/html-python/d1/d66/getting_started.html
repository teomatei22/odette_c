Getting Started

This guide will help you set up and start using the ODETTE Python Interface for satellite orbit visualization and propagation.

Prerequisites

System Requirements

  • Python 3.8+ with pip
  • C++ Compiler with C++17 support
  • CMake 3.12+ for building C++ extensions
  • Git for repository access

Required Python Packages

pip install numpy matplotlib pybind11 setuptools wheel

Optional Dependencies

pip install scipy pandas # For advanced analysis
pip install jupyter # For notebook examples

Installation

1. Clone the Repository

git clone https://github.com/teomatei22/odette_c.git
cd odette_c/Python_interface/Bindings_Python-interface-code

2. Build the C++ Extension

On Windows

Follow the detailed Windows Build Guide:

# Install Visual Studio Build Tools first
python setup.py build_ext --inplace

On Linux/macOS

# Install build dependencies
sudo apt-get install build-essential cmake libeigen3-dev # Ubuntu/Debian
# or
brew install cmake eigen # macOS
# Build the extension
python setup.py build_ext --inplace

3. Verify Installation

python -c "from odette import satellite_core; print('Module loaded successfully!')"

Basic Usage Examples

1. Simple TLE Visualization

from orbit_toolkit import OrbitVisualizer
# Create visualizer instance
visualizer = OrbitVisualizer()
# Sample TLE data (International Space Station)
tle_line1 = "1 25544U 98067A 08264.51782528 -.00002182 00000-0 -11606-4 0 2927"
tle_line2 = "2 25544 51.6416 247.4627 0006703 130.5360 325.0288 15.72125391563537"
# Visualize the orbit
fig, ax, positions = visualizer.visualize_tle(
tle_line1, tle_line2,
time_span_hours=6, # 6 hours of orbit
step_minutes=5, # 5-minute intervals
show_plot=True, # Display the plot
save_path="iss_orbit.png" # Save to file
)
print(f"Generated {len(positions)} orbital positions")

2. Orbit Propagation with Analysis

from orbit_toolkit import OrbitPropagator
import numpy as np
# Create propagator instance
propagator = OrbitPropagator()
# Propagate TLE orbit with detailed analysis
results = propagator.propagate_tle(
tle_line1, tle_line2,
time_span_hours=24, # Full day
step_minutes=10, # 10-minute steps
return_vectors=True # Include position/velocity
)
if results:
# Analyze orbital elements evolution
elements = results['orbital_elements']
# Extract semi-major axis evolution
sma_values = [oe['a'] for oe in elements]
times = np.array(results['epochs'])
print(f"Initial semi-major axis: {sma_values[0]:.3f} km")
print(f"Final semi-major axis: {sma_values[-1]:.3f} km")
print(f"Total change: {sma_values[-1] - sma_values[0]:.3f} km")

3. High-Precision RK45 Propagation

# Configure perturbation models
perturbations = {
'j2': True, # Earth oblateness
'third_body': True, # Moon/Sun effects
'solar_radiation': True, # Solar radiation pressure
'atmospheric_drag': False # Atmospheric drag (for LEO)
}
# RK45 numerical integration
rk45_results = propagator.propagate_rk45(
tdm_wildcard="data/*.tdm", # Observation files
delta=100, # TDM parsing tolerance
delta_error=30, # Error tolerance
time_span_hours=12,
perturbations=perturbations
)
if rk45_results:
print("RK45 propagation completed successfully")
print(f"Computed {len(rk45_results['epochs'])} epochs")

4. Comparative Analysis

# Compare TLE vs RK45 methods
fig, ax, tle_pos, rk45_pos = visualizer.compare_orbits(
tle_line1, tle_line2,
tdm_wildcard="data/*.tdm",
delta=100, delta_error=30,
time_span_hours=6,
perturbations_list=[
{'j2': True, 'third_body': False},
{'j2': True, 'third_body': True, 'solar_radiation': True}
],
save_path="orbit_comparison.png"
)
print("Orbit comparison visualization created")

5. Multiple Satellite Visualization

# Configure multiple satellites
satellites_data = [

'color': 'red',

Java Integration

Setting up the Bridge

from orbit_toolkit import JavaGUIBridge
import json
# Initialize bridge for Java communication
bridge = JavaGUIBridge()
# Set up progress callback (optional)
def progress_callback(percent, message):
print(f"Progress: {percent}% - {message}")
bridge.set_status_callback(progress_callback)

Executing Commands from Java

# Example command from Java GUI
command_json = json.dumps({
'command': 'visualize_tle',
'tle_line1': tle_line1,
'tle_line2': tle_line2,
'time_span_hours': 6,
'step_minutes': 5,
'save_path': 'gui_output.png',
'show_plot': False
})
# Execute command
result_json = bridge.execute_command(command_json)
result = json.loads(result_json)
if result['status'] == 'success':
print("Command executed successfully")
# Process result data
else:
print(f"Error: {result['message']}")

Configuration Management

Setting Perturbation Parameters

# Configure solar radiation pressure
srp_params = {
'CR': 1.8, # Coefficient of reflectivity
'Am': 0.01, # Area-to-mass ratio (m²/kg)
}
# Configure atmospheric drag
drag_params = {
'CD': 2.2, # Drag coefficient
}
# Apply parameters
success = propagator.set_perturbation_parameters(srp_params)
if success:
print("Perturbation parameters updated")
# Retrieve current parameters
current_params = propagator.get_perturbation_parameters()
print("Current parameters:", current_params)

Data Formats

TLE Format

Two-Line Element sets consist of two 69-character lines:

1 25544U 98067A 08264.51782528 -.00002182 00000-0 -11606-4 0 2927
2 25544 51.6416 247.4627 0006703 130.5360 325.0288 15.72125391563537

TDM Files

Tracking Data Message files contain observation data:

META_START
TIME_SYSTEM = UTC
REFERENCE_FRAME = EME2000
START_TIME = 2023-01-01T00:00:00.000
STOP_TIME = 2023-01-01T01:00:00.000
META_STOP
DATA_START
2023-01-01T00:00:00.000 123.456 45.678
2023-01-01T00:05:00.000 124.567 46.789
DATA_STOP

Troubleshooting

Common Issues

  1. Import Error: Ensure C++ extension is built correctly
    python setup.py build_ext --inplace --force
  2. Missing Dependencies: Install required packages
    pip install -r requirements.txt
  3. Compilation Errors: Check compiler and CMake installation
  4. Path Issues: Verify working directory contains the built extension

Performance Tips

  • Use appropriate time steps for your application
  • Enable only necessary perturbations for RK45
  • Cache results for repeated analyses
  • Use multiprocessing for batch operations

Solve for initial position and velocity vectors using Gauss\textquotesingle{}s method. 

This function takes at least three optical observations (each containing an epoch, station ECEF position, and right ascension/declination angles) and computes the approximate satellite state vectors (position and velocity) at the middle observation’s epoch. It uses the classical Gauss method of orbit determination\+:
\begin{DoxyEnumerate}
\item Converts observed RA/\+Dec to line-\/of-\/sight unit vectors.
\item Transforms station ECEF coordinates to ECI at each observation epoch.
\item Constructs the Lambert-\/like linear system to estimate slant ranges.
\item Solves a ninth‐degree polynomial for the middle slant range magnitude.
\item Computes the position vectors r1, r2, r3 in ECI coordinates.
\item Uses Gibbs method to estimate the velocity vector at r2.
\end{DoxyEnumerate}

{\footnotesize\ttfamily TDMData interpret\+::parse\+\_\+tdm (\begin{DoxyParamCaption}\item[{const std\+::string \&}]{filename }\end{DoxyParamCaption})}



Parse a single TDM (Tracking Data Message) file and extract observations. 

Opens the specified TDM file, reads the metadata between META\+\_\+\+START and META\+\_\+\+STOP markers, and reads observation lines between DATA\+\_\+\+START and DATA\+\_\+\+STOP. Metadata fields such as TIME\+\_\+\+SYSTEM, START\+\_\+\+TIME, STOP\+\_\+\+TIME, and REFERENCE\+\_\+\+FRAME are stored in the returned TDMData.\+meta structure. Station geodetic coordinates (longitude, latitude, altitude) are parsed from COMMENT lines and converted to an ECEF position. Observation lines consist of timestamp, right ascension (degrees), and declination (degrees). Each pair of lines yields one Observation entry with epoch (Julian date), ra (radians), dec (radians), and station\+ECEF (ECEF position in kilometers). All observations are stored in TDMData.\+observations.

Parse multiple TDM files matching a wildcard pattern and filter observations by time interval. 

Given a filesystem wildcard (e.\+g., \char`\"{}/path/to/dir/$\ast$.\+tdm\char`\"{}), this function\+:
\begin{DoxyEnumerate}
\item Extracts the directory and filename pattern from the wildcard string.
\item Iterates over all regular files in that directory whose names contain the pattern prefix.
\item Invokes \mbox{\hyperlink{namespaceinterpret_ae44eac0219a20cc0c64c5c325b78342b}{parse\+\_\+tdm()}} on each matching file to collect TDMData objects.
\item Merges all observations into a single TDMData, sorting them by epoch.
\item Filters the merged observations to include only those where the time difference from the previous selected observation is within \mbox{[}delta -\/ delta\+\_\+error, delta + delta\+\_\+error\mbox{]} seconds.
\item Returns the filtered, merged TDMData with metadata inherited from the first file.
\end{DoxyEnumerate}
